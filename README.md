\# TWA - Ficha 01



Exercícios de Tecnologias Web Avançadas.



\## Node API



Consumo da API pública do GitHub através de `fetch` e `async/await`.



O programa apresenta o nome e número de estrelas do repositório Node.js e guarda os dados num ficheiro `repo.json`.



\## Vite



Projeto Vanilla JavaScript criado com Vite.



Foi alterado o contador para contar de forma decrescente e o valor é também apresentado no título do separador do browser.



## Ficha 02

Nesta ficha foram trabalhados módulos JavaScript, funções puras e manipulação de arrays.

### Conteúdos

- Criação de dados num módulo `data.js`
- Funções em `catalogo.js`
- Utilização de:
  - `filter`
  - `map`
  - `reduce`
  - `toSorted`
  - `Set`
- Pesquisa por categoria
- Pesquisa por nome e tags
- Cálculo do valor total
- Seleção dos itens mais caros
- Aplicação de descontos sem alterar os dados originais
- Leitura de argumentos da linha de comandos com `process.argv`
- Testes automáticos com `node:assert/strict`
- Criação de um relatório em `report.json`

### Exemplos de utilização

```bash
node app.js
node app.js programming
node app.js search clean
node app.js top 3
node app.js report
